## English (en-US)

**Name** (30): Yeet – Dev Cache Cleaner

**Bundle ID:** vn.stevetran.yeet · **SKU:** yeet-macos

**Subtitle** (30): Clear developer caches safely

**Promotional text** (170):
See how much space build data, simulators, npm, Yarn, Gradle, Git and Claude Code are using — and clear it safely, with the exact path and impact shown for every folder.

**Keywords** (100):
deriveddata,cleaner,cache,npm,yarn,gradle,git,disk,storage,developer,simulator,claude,space,build

**Description** (4000):
Yeet finds the caches your developer tools leave behind and helps you clear them without guessing.

Developer caches grow quietly. DerivedData, Device Support, npm and Yarn caches, Gradle dependencies and old Git objects can easily take tens of gigabytes. Yeet scans them all in seconds, shows exactly where they live, and tells you what happens if you delete each one.

SUPPORTED TOOLS
• App builds — DerivedData per project, Device Support, Simulator caches, Documentation cache, developer tools cache
• CocoaPods, Swift Package Manager and Carthage caches
• pnpm, Bun, Python (pip, Poetry, uv), Go, Rust (Cargo + target/), Maven, Flutter & Dart
• Homebrew downloads and logs
• Old node_modules folders in your projects
• npm — _cacache, _npx, logs
• Yarn — Classic (v1) cache and Berry global cache
• Gradle — modules, transforms, build cache, wrapper distributions, daemon logs
• Claude Code — logs, shell snapshots, todos, and the Claude desktop Cowork VM image
• VS Code, Cursor and old JetBrains IDE caches
• App caches (Slack, Discord, Chrome…), crash reports, logs, Trash, installers in Downloads, device firmware files

KNOW BEFORE YOU DELETE
• Full path, size, file count and last modified date for every item
• A clear level for each item: Safe or Re-download. Anything that can't be recreated — app archives, device backups, chat history — is never listed
• A plain explanation of what deleting will affect
• Exactly which folder or file will be removed

CLEAN SAFELY
• Select Safe items in one click — only caches that rebuild themselves
• Review everything in a confirmation sheet before it’s removed
• Yeet asks you to quit an app before clearing its cache
• Copy any path or reveal it in Finder

PRIVATE BY DESIGN
Yeet runs entirely on your Mac. It doesn’t collect, upload or share any data. On first launch you choose your Home folder so Yeet can read the caches; you can revoke this at any time in Settings.

Yeet is not affiliated with Apple, npm, Yarn, Gradle, Git or Anthropic. Product names are used only to identify the caches the app supports.

**What’s New** (v1.0):
First release. Scan and clean caches for app builds, npm, Yarn, Gradle, Git and Claude Code.

Yeet tìm cache mà các công cụ lập trình để lại và giúp bạn dọn chúng mà không phải đoán.

Cache của dev tăng lên âm thầm. DerivedData, Device Support, cache npm và Yarn, dependency của Gradle và object Git cũ có thể chiếm đến hàng chục GB. Yeet quét tất cả trong vài giây, cho biết chính xác chúng nằm ở đâu và điều gì xảy ra nếu bạn xoá từng mục.

• pnpm, Bun, Python (pip, Poetry, uv), Go, Rust (Cargo + target/), Maven, Flutter & Dart

• Gradle — modules, transforms, build cache, wrapper, log daemon
• Claude Code — log, shell snapshot, todo và ổ đĩa máy ảo Cowork của Claude desktop
• Cache VS Code, Cursor và các phiên bản JetBrains cũ
• Cache ứng dụng (Slack, Discord, Chrome…), báo cáo crash, log, Thùng rác, bộ cài trong Downloads, file firmware thiết bị

HIỂU RÕ TRƯỚC KHI XOÁ

• Mức độ rõ ràng cho từng mục: An toàn hoặc Tải lại. Những gì không tạo lại được — archive của app, bản sao lưu thiết bị, lịch sử trò chuyện — không bao giờ được liệt kê
• Giải thích ngắn gọn việc xoá sẽ ảnh hưởng gì

RIÊNG TƯ
Yeet chạy hoàn toàn trên máy Mac của bạn. Không thu thập, tải lên hay chia sẻ dữ liệu. Lần đầu mở, bạn chọn thư mục Home để Yeet đọc được cache; có thể thu hồi quyền bất cứ lúc nào trong Cài đặt.

Yeet không liên kết với Apple, npm, Yarn, Gradle, Git hay Anthropic. Tên sản phẩm chỉ được dùng để chỉ loại cache mà ứng dụng hỗ trợ.
